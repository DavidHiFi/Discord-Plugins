# Contributing

Thanks for helping with the plugins. Reports and fixes both help.

## Ways to help

- Report plugin bugs with the plugin name, the client and what you expected
- Send TypeScript fixes for existing plugins
- Suggest settings that would make a plugin easier to use

## Getting set up

```
npm install
```

## Checks before a pull request

```
npm test
```

The tests run against synthetic samples and a cached fixture, so no live client is needed.

## Where to submit

Open issues and pull requests in this repository.
